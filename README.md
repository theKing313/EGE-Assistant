# 💡 SmartEGE — Chrome Extension

Умный ассистент для подготовки к ЕГЭ/ОГЭ. Автоматически добавляет кнопки-подсказки 💡 к каждому заданию на поддерживаемых учебных сайтах.

---

```
SmartEGE/

├── vite.config.js                 # Vite + CRXJS конфигурация
├── package.json

│
├── public/
│   ├── knowledge/

│
└── src/
    ├── main.jsx                   # Popup: точка входа React
    ├── App.jsx                    # Popup: компонент приложения
    ├── App.css                    # Popup: стили
    │
    ├── content/
    │   ├── content.js             # Content Script: точка входа
    │   └── scanner.js             # Обнаружение заданий на странице
    │
    ├── components/
    │   ├── Lamp/
    │   │   ├── Lamp.jsx           # Кнопка 💡 с состоянием
    │   │   └── Lamp.css           # Стили кнопки
    │   └── Tooltip/
    │       ├── Tooltip.jsx        # Тултип с темой/правилом/подсказкой
    │       └── Tooltip.css        # Стили тултипа

    └── utils/

        └── domHelper.js           # Внедрение элементов в DOM
```

## ⚡ Быстрый старт

### 1. Требования

- Node.js 18+
- pnpm или npm

### 2. Установка зависимостей

```bash
cd SmartEGE
npm install
# или
pnpm install
```

### 3. Сборка расширения

```bash
npm run build
# или
pnpm run build
```

Готовая сборка появится в папке `dist/`.

---

## 🔧 Разработка (Dev-режим)

```bash
npm run dev
```

CRXJS автоматически пересобирает расширение при изменении файлов и поддерживает Hot Module Replacement (HMR).

> **Важно:** В dev-режиме расширение всё равно нужно загрузить в Chrome вручную (см. ниже). При изменении файлов достаточно нажать кнопку обновления на странице `chrome://extensions`.

## 🚀 Загрузка расширения в Chrome

### Шаг 1 — Откройте страницу расширений

Введите в адресной строке:
```
chrome://extensions
```

### Шаг 2 — Включите режим разработчика

В правом верхнем углу страницы переключите тумблер **«Режим разработчика» / «Developer mode»**.

### Шаг 3 — Загрузите папку

Нажмите кнопку **«Загрузить распакованное» / «Load unpacked»**.

Выберите папку:
- **После сборки (`npm run build`):** выберите папку `SmartEGE/dist/`
- **В dev-режиме (`npm run dev`):** выберите папку `SmartEGE/dist/` (CRXJS создаёт её автоматически)

### Шаг 4 — Готово!

Расширение SmartEGE появится в списке. Перейдите на любой из поддерживаемых сайтов — рядом с каждым заданием появится кнопка **💡 Подсказка**.

## 📚 База знаний

Файлы в `public/knowledge/` содержат подсказки к заданиям ЕГЭ:

- **`russian.json`** — задания 4–22 (ударения, паронимы, орфография, пунктуация и т.д.)
- **`math.json`** — задания 1–14 (проценты, геометрия, функции, тригонометрия и т.д.)

### Формат записи

```json
{
  "id": "ru_01",
  "taskNumbers": [4],
  "topic": "Орфоэпические нормы — ударение",
  "keywords": ["ударение", "произношение"],
  "rule": "Краткое объяснение правила...",
  "hint": "Практическая подсказка...",
  "example": "Пример использования правила..."
}
```

Добавляй новые предметы, создавая файл `public/knowledge/<subject>.json` и регистрируя его в `src/services/knowledgeService.js`.

## 🐛 Устранение проблем

**Кнопки 💡 не появляются на странице**
- Убедись, что расширение включено на странице `chrome://extensions`
- Проверь, что сайт входит в список поддерживаемых
- Открой DevTools → Console и ищи логи `[SmartEGE]`

**Ошибка при сборке**
- Убедись, что Node.js >= 18
- Удали `node_modules` и переустанови: `rm -rf node_modules && npm install`

**CRXJS не работает с Vite 5**
- Временное решение: используй `npm run build` вместо `npm run dev` и перезагружай расширение вручную
